# Codebase Map — Astra Customizer Reset

## Directory Structure

```
reset-astra-customizer/
├── class-astra-theme-customizer-reset.php  # Plugin entry point: reset flag, AJAX reset, script data
├── assets/
│   ├── css/unminified/customizer-reset.css      # Source: Reset All button and menu styles (LTR)
│   ├── css/unminified/customizer-reset-rtl.css  # Generated by `grunt rtl`
│   ├── css/minified/*.min.css, *.min-rtl.css    # Generated by `npm run build`
│   ├── js/unminified/customizer-reset.js        # Source: Reset All menu, previews, backup link
│   └── js/minified/customizer-reset.min.js      # Generated by `npm run build`
├── languages/                             # Translation template (.pot)
├── .distignore                            # WordPress.org distribution exclusions
├── .gitignore                             # Git exclusions
├── Gruntfile.js                           # Grunt build configuration
├── package.json                           # Node.js dependencies
├── CLAUDE.md                              # Claude Code project context
└── .claude/settings.json                  # Claude Code tool permissions
```
